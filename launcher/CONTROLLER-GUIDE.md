# Controller Guide

Connect a controller before launching the game. The PC Recomp runtime uses SDL gamepad support.

Open **Settings → Controls & Audio → Controller Button Prompts** to choose automatic prompts, Nintendo-style button positions, or Xbox-style positions. The `xbox_prompts` option also swaps the on-screen button labels; it requires the DKB build's Xbox prompt patch.

Motion controls, rumble, trigger rumble, and button prompts depend on the controller and the current DKB build. If a controller is not detected, reconnect it before launching and check the game's Controls settings.

The launcher and menu language default to English. Button mapping can be changed in the game's controls menu.
